# Experiment Roadmap

## Scoring

Each experiment is scored on:

- Expected Gain (1-10)
- Implementation Difficulty (1-10)
- Business Justification (1-10)
- Offline Validation Possible (1-10)
- Risk of Hurting Model (1-10, lower is better)

Priority Score =
(Expected Gain + Business + Offline + (10-Risk)) / Difficulty
